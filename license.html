ライセンス・データ出典

本サイトでは、駅データおよびOpenStreetMapの地理データを使用しています。 それぞれの出典とライセンスを以下に記載します。

駅・路線データ：station_database

駅・路線データには、 Seo-4d696b75 / station_database のデータを使用しています。

当該データは クリエイティブ・コモンズ 表示－継承 4.0 国際（CC BY-SA 4.0） の下で提供されています。

本サイトでは、駅データを基本的に元のデータのまま参照し、地図上の表示や計算に使用しています。

データの正確性・完全性・最新性は保証されていません。 元リポジトリに記載された利用上の注意および免責事項もご確認ください。

OpenStreetMap の路線データ

路線等の地理データには、 OpenStreetMap のデータを使用しています。データの取得には Overpass API を利用しています。

© OpenStreetMap contributors

OpenStreetMap のデータは Open Database License 1.0（ODbL） の下で提供されています。利用条件の詳細はリンク先をご確認ください。

本サイトでは、取得したOSMデータを基本的に元のデータのまま参照し、駅データとともに地図上の計算・表示に使用しています。

データの利用・加工について

本サイトでは、駅データとOpenStreetMapのデータを別々に保持し、表示や計算のために参照しています。 計算結果は地図上の表示に使用する場合があります。

OSMデータを利用して作成したデータベースがODbL上の「派生データベース」に該当する場合には、 ODbLに基づく追加の条件が適用されることがあります。 出典表示のみで、すべてのライセンス要件が満たされるとは限りません。

各データの権利は、それぞれの権利者・提供元に帰属します。

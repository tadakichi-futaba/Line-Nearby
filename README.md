# 路線近傍駅検索

地図上で指定した地点や路線の近傍にある駅を検索・表示する、Leaflet ベースの静的 Web アプリです。

## 主な機能

- 地図をクリックして近傍の駅を表示
- 路線・区間を選択して詳細を表示
- GPX、FlightAware の TrackLog、Overpass GeoJSON を読み込み
- 読み込んだ経路に近い駅を集計
- ボロノイ図、駅名、路線、始終点マーカーの表示を切り替え

## 起動方法

[GitHub Pages](https://tadakichi-futaba.github.io/Line-Nearby/) で公開しているページにブラウザからアクセスしてください。

ローカル環境で動作確認する場合は、ブラウザのセキュリティ制約を避けるため、ローカル Web サーバー経由で開いてください。

```powershell
python -m http.server 8000
```

起動後、<http://localhost:8000/> を開きます。
